## 9. 0x12345678 ORIGIN AUDIT

Source analysis of Wine repository (`wine/dlls/avrt/main.c:73`):

```c
HANDLE WINAPI AvSetMmThreadCharacteristicsW(const WCHAR *name, DWORD *index)
{
    FIXME("(%s,%p): stub\n", debugstr_w(name), index);

    if (!name)
    {
        SetLastError(ERROR_INVALID_TASK_NAME);
        return NULL;
    }

    if (!index)
    {
        SetLastError(ERROR_INVALID_HANDLE);
        return NULL;
    }

    return (HANDLE)0x12345678;
}
```

The return value `0x12345678` is compiled directly into the binary `/usr/lib/x86_64-linux-gnu/wine/x86_64-windows/avrt.dll` by Wine maintainers. It is NOT generated by Rine.
